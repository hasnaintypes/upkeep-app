# Dashboard

## Overview

A single view across every active project: current status, recent
incidents, and quick filters by tag, provider, or status.

## Projects

Every project you own, grouped by collection, with per-project actions:

- **Run check now** -- triggers an immediate health check outside the
  normal schedule and shows the result inline.
- **Pause / resume** -- stops or restarts scheduled checks without deleting
  the project's history.
- **Edit** -- opens the same sheet used to add a project, pre-filled.
- **Delete** -- permanently removes the project and everything derived from
  it (checks, incidents, notification rules). This can't be undone.

## Project detail

Each project's own page has:

- A response-time graph across configurable windows (24h/7d/30d/90d).
- An uptime heatmap.
- Incident history with an editable note per incident (e.g. "host
  maintenance" or a link to the fix).
- The raw check log.
- That project's attached notification rules.
- Settings for the project's fields (see [Projects & Health Checks](/docs/projects)),
  including its public status page toggle (see
  [Public Status Pages](/docs/status-pages)).

## Incidents

Every incident across every project you own, most recent first, filterable
by project, status, and time range -- the same per-incident data as each
project's own incident history, just not scoped to one project.

## API Keys

Generate and revoke per-user API keys for programmatic project registration
from a deploy step, instead of the **Add project** form. See
[API Keys](/docs/api-keys).

## Account and Settings

Reached from the user menu in the sidebar footer, not the main nav:

- **Account** (`/dashboard/account`) -- your signed-in email, changing your
  password, and permanently deleting your account (and everything it owns
  -- projects, checks, incidents, channels, API keys). Deletion requires
  typing your email to confirm and can't be undone.
- **Settings** (`/dashboard/settings`) -- app-level configuration, starting
  with notification channels (Discord, email, generic webhook) -- create a
  channel here, then attach it to projects from each project's own detail
  page. See [Notifications](/docs/notifications).
